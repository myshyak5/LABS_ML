<h1>Лабораторная работа №1</h1>
<h2>Реализация алгоритма линейной регрессии на Python</h2>
<h3>Описание задания к работе:<h3>
<ol>
    <li>Исходные данные представляют собой CSV файл с двумя столбцами.</li>
    <li>Реализовать чтение данных из файла.</li>
    <li>Вывести статистическую информацию о используемых данных (количество, min, max, среднее) по каждому из столбцов.</li>
    <li>Используя библиотеку Matplotlib вывести изображение исходных точек.</li>
    <li>Реализовать алгоритм метода наименьших квадратов и вычислить параметры регрессионной прямой.</li>
    <li>Используя библиотеку Matplotlib и полученное в п.3 изображение отрисовать на изображении другим цветом полученную прямую.</li>
    <li>Используя полученное в п.5 изображение, отрисовать и заштриховать квадраты ошибок.</li>
</ol>
<p>
<b>Общие замечания:</b> программа должна позволять работать с другими входными файлами, программа должна позволять выбрать какой из входных столбцов выбрать в качестве Х а какой в качестве У (в случае если столбцов больше 2), по завершению программы должны одновременно видны все 3 изображения (п.4, п.5, п.6)
</p>
